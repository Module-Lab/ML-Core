# ModLEX Core

Модульная платформа для Minecraft: один лёгкий клиентский мод (ядро), к которому подключаются
отдельные модули. Ядро сглаживает различия версий Minecraft и загрузчиков — модули пишутся против
тонкого контракта и работают везде, где есть Core.

Это публичный репозиторий: здесь обсуждения, вопросы и готовые сборки (**Releases**). Исходники ядра закрыты.

## Возможности
- HUD- и 3D-оверлеи, звук, модели, данные игрока и мира;
- официальные модули: **музыка** (SoundCloud, локальные файлы, радио; плашка «сейчас играет»,
  мини-плеер, избранное, плейлисты) и **скины** (резолвер Mojang / ElyBy / BlessingSkin);
- установка модулей перетаскиванием в папку `modlex-modules/`, горячая перезагрузка,
  компиляция `.java`-модулей без JDK.

## Установка
1. Нужен **Fabric** (текущая сборка — под **Minecraft 1.16.5**).
2. Скачай последний `modlex-core-*.jar` из [Releases](https://github.com/Module-Lab/ML-Core/releases) и положи в папку `mods`.
3. Мод клиентский — на сервер ничего ставить не нужно.

## Разработчикам модулей
Бери SDK-артефакты (API-либа + компилятор) из [Releases](https://github.com/Module-Lab/ML-Core/releases) — они помечены как `SDK`.
