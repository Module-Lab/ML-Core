# Безопасность

Сообщить об уязвимости можно приватно:

- через **GitHub Security Advisories**: вкладка *Security* → *Report a vulnerability*
  (приватный тикет, виден только мейнтейнерам);
- либо написать мейнтейнерам организации **Module-Lab** в личные сообщения.

Пожалуйста, не публикуй детали в Issues, пока уязвимость не закрыта.
